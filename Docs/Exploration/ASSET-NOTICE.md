# Expedition Mk.I asset provenance

Design direction: NARK / SS14 Project. Based on the approved Expedition Drop
Armor Mk.I concept from this conversation, dated 2026-09-28. No identification
stripe is included.

The five custom RSI folders contain original pixel geometry authored for this
project. No upstream sprite pixels or Halo artwork are copied into these PNGs.
An AI-generated concept informed the design; this is a separate native-pixel
implementation, not code or sprites extracted from a presentation graphic.

owner has not selected an open redistribution license for these new assets.
